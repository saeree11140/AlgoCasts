SQL · 10 นาที · 10 คะแนน

เขียน query เดียวที่กรองกลุ่มข้อมูล แล้วแสดงผลตามลำดับและรูปแบบที่โจทย์กำหนดให้ตรงทุกจุด

หาแผนกที่มีเงินเดือนเฉลี่ยสูง

ข้อมูลพนักงานของบริษัทเก็บอยู่ในตาราง EMPLOYEE ให้แสดงชื่อทุกแผนกที่มีพนักงานอย่างน้อย 2 คน และมีเงินเดือนเฉลี่ยมากกว่า 50000 (ไม่รวมเท่ากับ) พร้อมเงินเดือนเฉลี่ยนั้นที่ปัดเป็นทศนิยม 2 ตำแหน่ง เรียงผลลัพธ์ตามเงินเดือนเฉลี่ยจากมากไปน้อย ถ้าสองแผนกมีเงินเดือนเฉลี่ยเท่ากัน ให้เรียงตามชื่อแผนกจากน้อยไปมาก (A → Z)

เฉลย รันบน PostgreSQL 16 แล้ว

SQL
SELECT DEPARTMENT, ROUND(AVG(SALARY), 2) AS AVG_SALARY
FROM EMPLOYEE
GROUP BY DEPARTMENT
HAVING COUNT(*) >= 2 AND AVG(SALARY) > 50000
ORDER BY AVG(SALARY) DESC, DEPARTMENT;

เงื่อนไขที่ใช้กับ “ค่าที่คำนวณจากกลุ่ม” ต้องอยู่ใน HAVING ไม่ใช่ WHERE (WHERE กรองแถวก่อนจัดกลุ่ม) การเรียงด้วย AVG(SALARY) ตรง ๆ แทนค่าที่ปัดแล้วทำให้ลำดับไม่เพี้ยนเมื่อค่าเฉลี่ยใกล้กัน

กับดักที่ข้อมูลตัวอย่างวางไว้ (ลองรันคำตอบผิดแล้ว)

คำตอบผิดผลที่ได้
ใช้ WHERE SALARY > 50000 แทน HAVING AVG(SALARY) > 50000ได้ 5 แถว HR และ Operations โผล่ และค่าเฉลี่ยผิด เพราะกรองรายคนก่อนเฉลี่ย
ลืม COUNT(*) >= 2HR (พนักงานคนเดียว เงินเดือน 70000) โผล่เป็นแถวแรก
ใช้ >= 50000Operations ที่เฉลี่ย 50000.00 พอดีโผล่ทั้งที่ไม่ควร
เฉลี่ยแบบจำนวนเต็ม (เช่น SUM/COUNT ของ int)Engineering ได้ 62333 แทน 62333.33

ความต่างระหว่าง DBMS ยังไม่ได้รันทดสอบ

  • MySQL, PostgreSQL, Oracle: ROUND(AVG(SALARY), 2) ใช้ได้เหมือนกัน
  • SQL Server (T-SQL): AVG ของคอลัมน์จำนวนเต็มคืนค่าจำนวนเต็ม (ตัดทศนิยม) ต้องแปลงก่อน เช่น ROUND(AVG(CAST(SALARY AS DECIMAL(12,2))), 2)
  • การแสดงผลทศนิยมของตัวเลข (เช่น 53750 กับ 53750.00) ขึ้นกับ DBMS และเครื่องมือแสดงผล ให้ดูจาก Sample Output ของข้อสอบจริง

ส่วนนี้อ้างจากความรู้ทั่วไป ควรเทียบกับเอกสารของ DBMS ที่เลือกใช้

The log below contains lines in this exact format:
<Page Name> - Viewed <N> time(s)

ตัวตรวจอ้างอิง (โค้ด Python ตามกติกา ใช้ยืนยันผลที่คาด ไม่ใช่ตัวตรวจ prompt)

Python
import re

LINE = re.compile(r'^(.+) - Viewed (\d+) times?$')

def solve(log: str) -> str:
    """ตัวตรวจอ้างอิงตามกติกาในโจทย์ (ไม่ใช่ LLM) ใช้ยืนยันว่าเทสต์ทุกข้อสอดคล้องกับกติกา"""
    totals = {}
    for line in log.split('\n'):
        m = LINE.match(line.strip())
        if not m:
            continue                      # ข้ามบรรทัดที่ไม่ตรงรูปแบบ
        name, n = m.group(1), int(m.group(2))
        totals[name] = totals.get(name, 0) + n   # รวมชื่อเดียวกัน (case-sensitive)
    best_name, best_total = None, -1
    for name, total in totals.items():    # dict เรียงตามที่เจอก่อน -> เสมอให้เอาตัวที่ปรากฏก่อน
        if total > best_total:
            best_name, best_total = name, total
    return f"{best_name},{best_total}"

แนวคิด

หาจำนวนเฉพาะทั้งหมดถึง n ด้วยตะแกรงของเอราทอสเทนีสครั้งเดียว (sieve) แล้ววนจาก 1 ถึง n ตรวจเงื่อนไขตามลำดับ จำนวนเฉพาะก่อน แล้วจำนวนกำลังสอง แล้วเลขคู่ ถ้าไม่เข้าเงื่อนไขใดให้พิมพ์ตัวเลข การตรวจจำนวนกำลังสองให้ใช้รากที่ปัดเป็นจำนวนเต็มแล้วยกกำลังสองเทียบ ไม่ควรเทียบทศนิยมตรง ๆ

Complexity: เวลา O(n log log n) · พื้นที่ O(n) (ถ้าตรวจจำนวนเฉพาะทีละตัวด้วยการหารถึง √i จะเป็น O(n√n) ซึ่งเทสต์ใหญ่ยังผ่านในภาษาที่เร็ว แต่การหารถึง i เป็น O(n²) จะล้ม)

Python
def number_labels(n):
    # sieve of Eratosthenes: is_prime[i] เป็นจริงเมื่อ i เป็นจำนวนเฉพาะ
    is_prime = [True] * (n + 1)
    is_prime[0] = False
    if n >= 1:
        is_prime[1] = False
    i = 2
    while i * i <= n:
        if is_prime[i]:
            for j in range(i * i, n + 1, i):
                is_prime[j] = False
        i += 1

    out = []
    for i in range(1, n + 1):
        root = int(i ** 0.5 + 0.5)
        if is_prime[i]:
            out.append("Prime")
        elif root * root == i:          # จำนวนกำลังสอง (รวม 1)
            out.append("Square")
        elif i % 2 == 0:
            out.append("Even")
        else:
            out.append(str(i))
    print("\n".join(out))

JavaScript รันแล้ว

JavaScript
function numberLabels(n) {
  const isPrime = new Array(n + 1).fill(true);
  isPrime[0] = false;
  if (n >= 1) isPrime[1] = false;
  for (let i = 2; i * i <= n; i++) {
    if (isPrime[i]) {
      for (let j = i * i; j <= n; j += i) isPrime[j] = false;
    }
  }
  const out = [];
  for (let i = 1; i <= n; i++) {
    const r = Math.round(Math.sqrt(i));
    if (isPrime[i]) out.push("Prime");
    else if (r * r === i) out.push("Square");
    else if (i % 2 === 0) out.push("Even");
    else out.push(String(i));
  }
  console.log(out.join("\n"));
}

ข้อผิดพลาดที่พบบ่อย

  • ถือว่า 1 เป็นจำนวนเฉพาะ (1 ต้องเป็น Square)
  • ตรวจ Even ก่อน Prime ทำให้ 2 ถูกพิมพ์เป็น Even แทนที่จะเป็น Prime
  • ตรวจ Even ก่อน Square ทำให้ 4, 16, 36 พิมพ์เป็น Even แทน Square
  • ตรวจจำนวนกำลังสองด้วย sqrt(i) == (int) sqrt(i) กับทศนิยมตรง ๆ อาจพลาดจากความคลาดเคลื่อน ควรใช้รากปัดเป็นจำนวนเต็มแล้วยกกำลังสองเทียบ
  • วนหารตั้งแต่ 2 ถึง i - 1 ต่อทุกตัว (O(n²)) ล้มเทสต์ใหญ่
  • ในภาษาที่ int เป็น 32 บิต ตัวแปรที่คูณ p * p เมื่อ p ใหญ่ถึง 200,000 จะล้น ให้วน p เฉพาะที่ p * p <= n หรือใช้ชนิดข้อมูล 64 บิต
  • พิมพ์ทีละบรรทัดด้วย I/O ที่ช้าในบางภาษา ถ้าช้าให้รวมผลลัพธ์เป็นสตริงเดียวก่อนพิมพ์
